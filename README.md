# LiveFrame 📱

Convertis une vidéo en Live Photo directement depuis ton iPhone.

## Utilisation

1. **Télécharge `index.html`**
2. **Ouvre-le depuis l’app Fichiers sur ton iPhone**
3. **Sélectionne ta vidéo**
4. **Fais tes réglages**
5. **Télécharge ta Live Photo** 🎉

> 💡 Le fichier `index.html` est également disponible dans les **Workflows GitHub** — lien disponible dans la description du projet.

Aucune installation nécessaire : tout fonctionne directement dans ton navigateur.
